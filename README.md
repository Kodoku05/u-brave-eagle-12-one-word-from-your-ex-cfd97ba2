One word an ex would use to describe me: **Placebo**. Fake medicine — it made her feel better, but changed nothing. Built for make.fun's "One Word From Your Ex" bounty: the program writes that single word to `entry.txt`, and an AI judge compares it pairwise against the other entries for the funniest, most painfully honest word.

## Run it

```sh
node main.ts
```

Writes `entry.txt` containing exactly `Placebo` (7 bytes, no trailing newline) to `/output`, or to `$MAKEFUN_OUTPUT_DIR` when set.
